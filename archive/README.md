# Supporting research records

This ZIP preserves the complete previously distributed research snapshot and
current raw experiment records. Extract it into a separate directory when
inspecting supporting experiments. It contains all archived branches, trials,
protocols, legacy diagnostics, transfer and carrier records, and the superseded
reliability record alongside `results_v2`. Results have not been edited to match
the two-branch presentation in the main package.

The main package presents the current waveform-only/hybrid ablation. Its JSON
views are documented projections of these complete records, not a replacement
for the original measurements. The archive includes per-file SHA-256 checks.
Large arrays remain separate Release assets; the external Overthrust export is
not redistributed. Historical runner/hash limitations apply to the archive.
